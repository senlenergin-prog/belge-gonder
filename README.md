# Belge Gönder

Çalışanların fiş, fatura, çek ve senet fotoğraflarını muhasebeye gönderdiği küçük web uygulaması (PWA).

- Veriler: Supabase projesi `muhasebe-belgeler` (Frankfurt). Fotoğraflar gizli `belgeler` deposunda.
- Yetki: göndericiler yalnızca kendi gönderilerini görür; durumu değiştiremez, kullanıcı ekleyemez.
- Yönetici: tüm belgeleri görür, işler/reddeder, kullanıcı ekler, şifre belirler.
- Bu depoda yalnızca uygulama kodu vardır; hiçbir muhasebe verisi veya fotoğraf bulunmaz.

## Yayınlama
GitHub Pages: Settings → Pages → Branch: `main` / root.

## iPhone'a kurulum
Safari'de adresi açın → Paylaş → Ana Ekrana Ekle.
